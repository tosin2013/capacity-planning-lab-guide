= Strategic Capacity Planning & Forecasting for OpenShift at Scale

A full-day, highly interactive workshop designed to help platform engineering and development teams transition from reactive "firefighting" to predictive, data-driven capacity management using OpenShift and Red Hat Advanced Cluster Management (RHACM).

== Workshop Overview

This workshop teaches strategic capacity planning through 9 comprehensive modules covering:

* **Module 1**: The Planning Horizon & 90-Day Audit - Establish capacity baselines
* **Module 2**: Mathematics of Forecasting - Pod Velocity Model and PromQL
* **Module 3**: Developer Track - QoS classes, right-sizing, and HPA
* **Module 4**: The Right-Sizing Activity - Ops-meets-dev collaborative dashboard diagnosis
* **Module 5**: Infrastructure Track - Node density, etcd limits, split vs grow decisions
* **Module 6**: Fleet Observability (RHACM) - Multi-cluster dashboards and metric allowlists
* **Module 7**: Integration Challenge - Black Friday chaos game simulation
* **Module 8**: Strategic Roadmapping - 12-month capacity planning and executive communication
* **Module 9**: AI-Assisted Capacity Operations with OpenShift Lightspeed _(Optional)_

**Duration**: 8 hours (full-day workshop)

**Target Audience**: Platform Engineers, SREs, Application Developers, Architects, FinOps practitioners

== Accessing the Workshop

**Public Documentation**: https://tosin2013.github.io/capacity-planning-lab-guide

**For Instructors**: Deploy via AgnosticD workload `ocp4_workload_capacity_planning_workshop` on Red Hat Demo Platform (RHDP) to create a complete workshop environment with Showroom lab guide and pre-deployed sample applications. == Quick Start

Automated onboarding handles prerequisites, configuration, and validation. See link:docs/quickstart.md[Quick Start Guide] for the full 5-minute walkthrough.

[source,sh]
----
# End users — deploy a workshop environment:
make setup        # interactive onboarding (installs tools, configures AWS)
make dry-run      # preview deploy commands without executing
make deploy       # provision hub + student clusters (~3-4 hours)

# Maintainers — local content development:
make setup-dev    # install dev tools (shellcheck, yamllint, nodejs)
make build        # build Antora site locally
make serve        # preview at http://localhost:8080
----

Run `make help` to see all available targets. The link:bootstrap.sh[bootstrap.sh] script can also be run directly without Make.

Test and develop the lab guide locally using Podman or Docker:

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer

[source,sh]

== Workshop Attributes

The workshop uses Antora attributes for dynamic content substitution. When deploying via RHDP, these are automatically populated:

* `{guid}` - Student's unique workshop instance identifier
* `{cluster_domain}` - OpenShift cluster ingress domain
* `{openshift_console}` - OpenShift web console URL
* `{namespace}` - Student's workshop namespace
* `{rhacm_console}` - RHACM console URL
* `{grafana_url}` - Observability Grafana URL

For local development or GitHub Pages, these use placeholder values.
